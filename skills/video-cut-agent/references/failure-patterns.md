# Failure Patterns

Promote a problem here after it appears more than once or causes a failed
delivery. Promote it into a gate when it is automatically detectable.

## Current gate-backed patterns

- Missing or unreadable source asset.
- Missing transcript for an audio item.
- Subtitle segment with an invalid or reversed timestamp.
- Output aspect ratio differs from the platform target.
- Render, subtitle, manifest, or log missing for a delivered short.
- Multiple variants reuse the same opening source.

## Candidate patterns

- Captions cover a product or face.
- B-roll contradicts the spoken sentence.
- Long static sections reduce retention.
- Speech pace and cut pace feel mismatched.
