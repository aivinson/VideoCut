# Editing Principles

- Put a concrete hook in the first 3 seconds.
- Match visual changes to speech beats rather than fixed intervals only.
- Avoid repeating the same first shot across variants.
- Keep captions inside a vertical-video safe area.
- Prefer clear, inspectable source footage over atmospheric filler.
- Every variant should have a distinct opening, clip order, or narrative angle.
- Rough cuts should be traceable through manifests before creative polish.
